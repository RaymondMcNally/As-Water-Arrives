    Blend the two images

    In the band between the dashed lines each projector fades out as the other fades in. If the band looks brighter than the rest, raise the gamma; if it looks darker, lower it. The band must lie where both pictures overlap.

    How the tiles were printed

    These set the height of each point on the model, so the image lands on the hills rather than beside them. The printed set uses 9 mm, −3 m and 1×.

    Live traffic (optional, TomTom)

    Paste a TomTom API key (free from developer.tomtom.com). It is kept in this browser only, never in the website's files, and the kiosk and projector windows use it too.
